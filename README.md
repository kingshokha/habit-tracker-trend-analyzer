# HabitTracker Trend Analyzer

Анализатор тренда и динмаики привычки на основе импорта истории в форматах ZIP (с `Scores.csv`), CSV или Excel.

## 🚀 Возможности
- **Аналитика показателей**: Общий успех за всё время, MTD (накопительный сравнение 6 месяцев) и YTD (год к году).
- **Сравнение месяцев**: Ранжирование всех месяцев истории, выявление лучших и худших периодов.
- **Хронология дня**: Просмотр динамики по дням, неделям, месяцам, кварталам и годам со специальными порогами цветовой индикации.
- **Рекорды**: Топ самых длинных серий успехов и провалов.
- **Статистика**: График накопительного успеха с опцией **«Учитывать с начала истории»** для отслеживания глобального тренда.
- **Удобный импорт**: Мгновенный Drag & Drop файлов при первом входе.

## 💻 Использование
Откройте `index.html` в любом современном веб-браузере. Все данные обрабатываются исключительно локально на вашей машине.
